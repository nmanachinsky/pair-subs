# Pair Subs — живой перевод пары EN→RU

Одностраничник: телефон лежит рядом с планшетом (или динамиком), слушает английскую речь и показывает
перевод на русский в реальном времени. Стек: Web Speech API (распознавание, Chrome) + DeepSeek API (перевод, стриминг).

Открыть: https://nmanachinsky.github.io/pair-subs/

## Как пользоваться

1. Открой страницу в **Chrome на Android** (микрофон и распознавание работают только под https — Pages даёт https).
2. **⚙️** → вставь DeepSeek API-ключ.
3. Положи телефон рядом с динамиком планшета. В Teams включи звук погромче (лучше — громкая связь, не наушники).
4. Нажми **«Старт»**. Экран телефона = субтитры: перевод крупно, оригинал мелко.

Кнопки:

- **💡** — «Что ответить?»: по последним репликам пары предлагает варианты ответа (для вопросов) или уточняющий вопрос (для объяснений).
- **⬇️** — экспорт транскрипта в Markdown.
- **🗑️** — очистить.

## Приватность и ключ

- Ключ API хранится только в `localStorage` браузера телефона и отправляется только на `api.deepseek.com`.
- В коде страницы и в репозитории ключа нет. GitHub Secrets для статики на Pages не используются: у страницы нет рантайма, а вшитый в сборку ключ стал бы публичным.
- Распознавание речи выполняет сервис Google (Web Speech API) — звук обрабатывается в облаке Google. Полностью офлайновый вариант — отдельная задача (whisper.cpp/sherpa-onnx на устройстве).

## Ограничения

- Только Chrome/Android. Chrome периодически сам останавливает распознавание — страница перезапускает его автоматически.
- Нужен интернет: и распознавание, и перевод работают через сеть.
- Задержка 2–5 секунд от фразы до перевода.
- Первое время работы перевод идёт без контекста — первые пары фраз могут быть менее точными, дальше модель подхватывает контекст.
- Запись/перевод занятия может противоречить правилам курса — согласуй с преподавателем.

## Локальный запуск

Скачай `index.html` и открой в Chrome. Для микрофона нужен `https` или `localhost`; на GitHub Pages https уже есть.

## Настройки в коде

- Модель: `deepseek-chat` (по умолчанию) или `deepseek-reasoner`.
- Глоссарий: строки вида `термин — перевод` уходят в системный промпт и заставляют переводить термины единообразно.
- Контекст: в запрос добавляются последние 8 пар «оригинал → перевод».
